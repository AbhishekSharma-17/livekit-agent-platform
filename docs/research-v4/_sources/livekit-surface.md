## 3. Text streams, data packets, byte streams, RPC (Python `livekit` rtc)

- Text streams: `local_participant.send_text()`, `stream_text()`, `room.register_text_stream_handler(topic, handler)`; stream info has `id, topic, timestamp, size, attributes, destinationIdentities`; "automatically chunked and streamed so there is no limit on string size"; no persistence; participants joining mid-stream do not receive it. https://docs.livekit.io/home/client/data/text-streams/ (accessed 2026-09-24)
- Agent topics: `lk.chat` (incoming text that triggers a reply) and `lk.transcription` (bidirectional transcriptions/text), with attributes `lk.transcribed_track_id`, `lk.segment_id`, `lk.transcription_final`; RoomIO options `text_enabled`, `transcription_enabled`, `sync_transcription`, `TextInputOptions(callback)`; legacy `publish_transcription()` deprecated. https://docs.livekit.io/agents/build/text/ (accessed 2026-09-24)
- Data packets: `publish_data()`; reliable max **15 KiB** per packet (ordered, retransmitted, still "best-effort"); lossy recommended **≤1,300 bytes**; optional `topic`, `destination_identities`. https://docs.livekit.io/home/client/data/packets/ (accessed 2026-09-24)
- Byte streams: `send_file(file_path=, topic=)`, `stream_bytes()` writer, `register_byte_stream_handler()`; recommended max chunk 15 KB; chunk boundaries not preserved; no mid-stream join. https://docs.livekit.io/home/client/data/byte-streams/ (accessed 2026-09-24)
- RPC: `register_rpc_method()` / `perform_rpc()`; payload max **15 KiB UTF-8** each way; default timeout 10 s; built-in error codes 1400/1401/1402/1500–1505, custom codes outside 1001–1999. https://docs.livekit.io/home/client/data/rpc/ (accessed 2026-09-24)

## 4. SIP: transfers, hold, AMD, attributes, headers

- **Cold transfer** = `TransferSIPParticipant` (SIP REFER) with `transfer_to` (`tel:`/`sip:`), `play_dialtone` (default false), `ringing_timeout` (default 30 s); session ends on success. https://docs.livekit.io/sip/transfer-cold/ (accessed 2026-09-24)
- **Warm transfer** recipe: hold caller, `CreateSIPParticipant` dials human into a private consultation room, agent briefs them, `MoveParticipant` moves human into caller's room. Prebuilt **`WarmTransferTask`** (`from livekit.agents.beta.workflows import WarmTransferTask`, Python beta only) with `sip_call_to`, `sip_trunk_id` / `sip_connection` (`SIPOutboundConfig`), `sip_number`, `sip_headers`, `dtmf`, `ringing_timeout`, **`hold_audio` (default `BuiltinAudioClip.HOLD_MUSIC`)**, `extra_instructions`, `tools`, `chat_ctx`; returns `WarmTransferResult(human_agent_identity)`; on timeout completes with `ToolError` and caller conversation resumes; SIP transferees only. https://docs.livekit.io/sip/transfer-warm/ and https://docs.livekit.io/agents/prebuilt/tasks/warm-transfer/ (accessed 2026-09-24). Example: https://github.com/livekit/agents/tree/main/examples/warm-transfer (files `support_agent.py`, `warm_transfer.py`, `twilio_connector_warm_transfer.py`) (accessed 2026-09-24)
- `MoveParticipant` (`lkapi.room.move_participant(MoveParticipantRequest(room, identity, destination_room))`) is **LiveKit Cloud only**. https://docs.livekit.io/home/server/managing-participants/ (accessed 2026-09-24)
- **Answering machine detection is native**: `from livekit.agents import AMD`; `async with AMD(session, participant_identity=...) as detector: result = await detector.execute()`; params `llm`, `stt`, `interrupt_on_machine` (default true), `ivr_detection` (Python only, default true), `wait_until_finished`; categories `human`, `machine-ivr`, `machine-vm`, `machine-unavailable`, `uncertain`; runs once at call start. https://docs.livekit.io/telephony/features/answering-machine-detection/ (accessed 2026-09-24). Blog (2026-05-13) states minimum livekit-agents **1.5.9 (Python)** / 1.4.2 (Node), so 1.8.2 has it. https://livekit.com/blog/answering-machine-detection (accessed 2026-09-24)
- `wait_until_answered` raises `SipCallError` on failure but voicemail answers with 200 OK, so use AMD. https://docs.livekit.io/sip/outbound-calls/ (accessed 2026-09-24)
- SIP participant attributes: `sip.callID`, `sip.callIDFull`, `sip.callStatus` (`active|automation|dialing|hangup|ringing`), `sip.phoneNumber`, `sip.ruleID`, `sip.trunkID`, `sip.trunkPhoneNumber`, `sip.twilio.accountSid/callSid`; custom `X-*` headers via `headers_to_attributes` (updated asynchronously). https://docs.livekit.io/reference/telephony/sip-participant/ (accessed 2026-09-24)
- `include_headers` accepts `SIP_NO_HEADERS | SIP_X_HEADERS | SIP_ALL_HEADERS`. https://docs.livekit.io/reference/telephony/sip-api/ (accessed 2026-09-24). The `sip.h.*` prefix appeared only in a search snippet, not on a fetched page: UNVERIFIED. `attributes_to_headers`: UNVERIFIED.
- "Whisper" (coach audible only to the human): no LiveKit-documented feature found (two searches). UNVERIFIED / likely not native.

## 5. Egress

- Five types via `StartEgress`: Room Composite, Web, Participant, Track Composite, Track; audio-only via `audio_only=true` (room composite, with mixing modes) or `AudioConfig` on track egress; audio-only billed lower. https://docs.livekit.io/home/egress/overview/ (accessed 2026-09-24)
- Outputs: MP4/WebM/OGG files, RTMP/RTMPS/SRT streams, HLS segments, periodic images; one egress can fan out to all types but "only a single item per type". https://docs.livekit.io/home/egress/outputs/ (accessed 2026-09-24)
- Start-before-join: **Participant egress "waits for the participant to join and publish tracks"**; Track Composite requires tracks published first; Room Composite ends when all participants leave. https://docs.livekit.io/home/egress/participant/ and https://docs.livekit.io/home/egress/room-composite/ (accessed 2026-09-24)
- **Auto egress**: set `egress` in `CreateRoom` to record composite and/or every track "as soon as it's created". https://docs.livekit.io/home/egress/autoegress/ (accessed 2026-09-24)
