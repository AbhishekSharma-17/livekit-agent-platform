# Voice-agent capability support matrix (as of 2026-09-24)

**Version caveat (read first).** Every LiveKit API name below was verified against the `livekit/agents` `main` branch or docs.livekit.io on 2026-09-24, not against a pinned `livekit-agents 1.8.x`. The 1.8.0 release notes (https://github.com/livekit/agents/releases/tag/livekit-agents%401.8.0 (accessed 2026-09-24)) confirm `set_tracer_provider(..., allow_pii=False)` / `LIVEKIT_TELEMETRY_ALLOW_PII=0` and a Twilio-connector warm-transfer PR (#6283), but do **not** mention `AMD`, `TurnHandlingOptions`, `RoomOptions`/`AudioInputOptions`, `livekit.agents.evals`, `video_input`, or the Palabra/Krisp-VIVA plugins. Notably, on `main` the `AgentSession` params `allow_interruptions`, `min_endpointing_delay`, `max_endpointing_delay`, `preemptive_generation` are **deprecated in favor of `turn_handling=TurnHandlingOptions(...)`** (https://raw.githubusercontent.com/livekit/agents/main/livekit-agents/livekit/agents/voice/agent_session.py (accessed 2026-09-24)), and the room-I/O shape is `RoomOptions(audio_input=AudioInputOptions(noise_cancellation=...))` while the PyPI snippet still shows `RoomInputOptions(noise_cancellation=...)`. Confirm each against your pinned version before estimating.

## 1. Multilingual / auto language detection / mid-call switching

- **Deepgram Nova-3 / Flux** — `language=multi` on the WebSocket; supported on Nova-2, Nova-3 and `flux-general-multi`; recommended `endpointing=100` for code-switching. Multi set is 10 languages: EN, ES, FR, DE, HI, RU, PT, JA, IT, NL (same 10 for Flux multi). https://developers.deepgram.com/docs/multilingual-code-switching, https://developers.deepgram.com/docs/models-languages-overview (accessed 2026-09-24).
  - LiveKit plugin: `deepgram.STT(model="nova-3", language="multi", detect_language=..., redact=..., keyterms=...)`; `SpeechStream.update_options(language=..., model=..., redact=...)` exists. https://raw.githubusercontent.com/livekit/agents/main/livekit-plugins/livekit-plugins-deepgram/livekit/plugins/deepgram/stt.py; https://docs.livekit.io/agents/models/stt/deepgram/ (accessed 2026-09-24).
- **Gladia** — real-time `language_config.languages` (list) + `language_config.code_switching: true`; doc warns not to enable code_switching with an empty language list (100+ language misdetection). https://docs.gladia.io/chapters/language/code-switching (accessed 2026-09-24). LiveKit plugin: `gladia.STT(languages=[...], code_switching=True, translation_enabled=..., translation_target_languages=[...])`, `update_options` accepts the same. https://raw.githubusercontent.com/livekit/agents/main/livekit-plugins/livekit-plugins-gladia/livekit/plugins/gladia/stt.py; https://docs.livekit.io/agents/models/stt/gladia/ (accessed 2026-09-24).
- **AssemblyAI** — LiveKit plugin exposes `language_detection`, `language_codes` (max 10, steering), `speech_model` (`universal-3-5-pro`, `universal-3-6-pro`), `keyterms_prompt`, `agent_context`; `update_options` accepts `language_codes`, `keyterms_prompt`, `prompt`, `agent_context`, endpointing params. https://raw.githubusercontent.com/livekit/agents/main/livekit-plugins/livekit-plugins-assemblyai/livekit/plugins/assemblyai/stt.py (accessed 2026-09-24). AssemblyAI's own multilingual-streaming doc pages 404'd — UNVERIFIED beyond the plugin source (search summary listed EN/ES/DE/FR/PT/IT).
- **Speechmatics** — plugin `speechmatics.STT(language="en", enable_diarization=..., additional_vocab=...)`; no translation/auto-detect params; end-of-utterance not configurable. https://raw.githubusercontent.com/livekit/agents/main/livekit-plugins/livekit-plugins-speechmatics/livekit/plugins/speechmatics/stt.py; https://docs.livekit.io/agents/models/stt/speechmatics/ (accessed 2026-09-24). Speechmatics language ID appears **batch-only** (only the batch page exists; real-time page 404) — UNVERIFIED for real-time. https://docs.speechmatics.com/speech-to-text/batch/language-identification (accessed 2026-09-24).
- **Google Cloud STT (Chirp 3)** — `language_codes=["auto"]` for auto-detect, or a list (`["en-US","fr-FR"]`); supports `StreamingRecognize`; `denoise_audio: True`. https://docs.cloud.google.com/speech-to-text/docs/models/chirp-3 (accessed 2026-09-24). LiveKit plugin: `google.STT(languages=..., detect_language=True, model="latest_long")`, `update_options(languages=..., detect_language=...)`. https://raw.githubusercontent.com/livekit/agents/main/livekit-plugins/livekit-plugins-google/livekit/plugins/google/stt.py (accessed 2026-09-24).
- **OpenAI STT** — `openai.STT(language: str|list[str]="en", detect_language=False, model="gpt-4o-mini-transcribe", prompt=...)`; `update_options(model, language, detect_language, prompt, keywords, turn_detection, noise_reduction_type, temperature)` — "Open streams apply the change in place; only a new `model` reconnects them." https://raw.githubusercontent.com/livekit/agents/main/livekit-plugins/livekit-plugins-openai/livekit/plugins/openai/stt.py (accessed 2026-09-24).
- **Palabra** — `palabra.STT(language=None  # server auto-detect, translate_languages=[...], filler_filter=...)`; `update_options(language, translate_languages, filler_filter)` — "Changes apply to new streams only." https://raw.githubusercontent.com/livekit/agents/main/livekit-plugins/livekit-plugins-palabra/livekit/plugins/palabra/stt.py (accessed 2026-09-24).
- **Gemini Live (realtime)** — "Converse in 70 supported languages"; capabilities page: 99 languages with automatic detection, native-audio models "switch between languages naturally"; no explicit `language_code` config found on those pages. https://ai.google.dev/gemini-api/docs/live-api, https://ai.google.dev/gemini-api/docs/live-api/capabilities (accessed 2026-09-24). LiveKit Gemini plugin page lists no `language` param. https://docs.livekit.io/agents/models/realtime/plugins/gemini/ (accessed 2026-09-24).
- **OpenAI Realtime** — LiveKit plugin page has no language info; language enforcement is prompt-driven only — UNVERIFIED. https://docs.livekit.io/agents/models/realtime/plugins/openai/ (accessed 2026-09-24).
- **ElevenLabs TTS language enforcement** — `language_code` (ISO 639-1) "used to enforce a language for the model and text normalization … not supported for multilingual_v2 models"; ignored if the model doesn't support it. https://elevenlabs.io/docs/api-reference/text-to-speech/convert (accessed 2026-09-24). Models: `eleven_v3` (70+ langs), `eleven_multilingual_v2` (29), `eleven_flash_v2_5` (32, ~75 ms), `eleven_turbo_v2_5` deprecated; agents recommended `eleven_v3_conversational`, `eleven_flash_v2_5`, `eleven_flash_v2`, `eleven_multilingual_v2`. https://elevenlabs.io/docs/overview/models (accessed 2026-09-24).

**`update_options(language=…)` mid-session summary (from plugin source):** Deepgram (yes, `language`), Google (yes, `languages`), OpenAI (yes, in-place), Gladia (yes, `languages`), Palabra (yes, new streams only), AssemblyAI (`language_codes` only), Speechmatics (no language update found).

## 2. Live translation

- **Palabra (LiveKit plugin)** — STT with `translate_languages`; emitted `SpeechData` has `language`/`text` = translation and `source_languages`/`source_texts` = original, so the agent can run without an LLM. Plugin dir has both `stt.py` and `tts.py`. https://raw.githubusercontent.com/livekit/agents/main/livekit-plugins/livekit-plugins-palabra/livekit/plugins/palabra/stt.py; https://github.com/livekit/agents/tree/main/livekit-plugins/livekit-plugins-palabra/livekit/plugins/palabra (accessed 2026-09-24).
- **Gladia** — `realtime_processing.translation_config { target_languages, model, match_original_utterances, lipsync, context_adaptation }`; returns `"type": "translation"` messages; multiple targets are processed sequentially (latency). https://support.gladia.io/article/how-to-combine-real-time-transcription-with-translation (accessed 2026-09-24). LiveKit plugin caveat: with >1 target language "the plugin emits a separate transcription event for each … which might confuse the LLM." https://docs.livekit.io/agents/models/stt/gladia/ (accessed 2026-09-24).
- **Speechmatics real-time** — `translation_config: { target_languages: [...], enable_partials: true }`, up to 5 targets, to/from English; messages `AddPartialTranslation` / `AddTranslation`. https://docs.speechmatics.com/speech-to-text/features/translation (accessed 2026-09-24). Not exposed in the LiveKit plugin.
- **Google Cloud** — Media Translation API deprecated (no longer available after July 1, 2024 per search); replacement is STT + Cloud Translation + TTS — UNVERIFIED (search only).
- **LiveKit example** — `livekit-examples/live-translated-captioning`: Deepgram STT → GPT-4o translation → captions per language via the transcription forwarder; text only, no TTS. https://github.com/livekit-examples/live-translated-captioning (accessed 2026-09-24).
- **Gemini 3.5 Live Translate** (speech-to-speech across 70+ languages) — search only, UNVERIFIED.
- **ElevenLabs dubbing / real-time** — not fetched, UNVERIFIED.

## 3. Voice cloning / instant clone / voice design

- **ElevenLabs** — IVC: few-shot, <2 min audio; PVC: fine-tune, ~30 min audio, Creator plan+; both use "voice-captcha technology" to verify the sample is your own voice; Voice Design generates a voice from text. https://elevenlabs.io/docs/eleven-api/concepts/voice-cloning; https://elevenlabs.io/docs/overview/capabilities/voices (accessed 2026-09-24). IVC API: `POST /v1/voices/add` (`name`, `files`, `remove_background_noise`, `description`, `labels`), response has `requires_verification`. https://elevenlabs.io/docs/api-reference/voices/ivc/create (accessed 2026-09-24). Voice Design: `POST /v1/text-to-voice/design` (`voice_description`, `model_id` = `eleven_multilingual_ttv_v2` | `eleven_ttv_v3`, `text` 100–1000 chars, `auto_generate_text`) → `generated_voice_id` → `/v1/text-to-voice`. https://elevenlabs.io/docs/api-reference/text-to-voice/design (accessed 2026-09-24).
- **Cartesia** — `POST /voices/clone` (`clip` ≤16 MB, `name`, `language`, optional `description`, `base_voice_id`, `tagline`, `accent`, `access`); instant clone from 10 s (up to 60 s on Sonic 3.6+), Pro clone ≥30 min. No consent text on the endpoint page. https://docs.cartesia.ai/api-reference/voices/clone; https://docs.cartesia.ai/build-with-cartesia/capability-guides/clone-voices (accessed 2026-09-24). Cartesia "voice design" — UNVERIFIED.
- **Hume Octave** — Octave 1 / Octave 2 (preview); voice design from a natural-language description (English only for now); save via `POST /v0/tts/voices`; cloning from ~15 s audio. https://dev.hume.ai/docs/text-to-speech-tts/overview (accessed 2026-09-24).
- **OpenAI** — no cloning endpoint found (not fetched) — UNVERIFIED.
- **PlayHT** — search says products discontinued after Meta's 2025 PlayAI acquisition — UNVERIFIED. **Resemble** — video consent required to clone third parties (search only) — UNVERIFIED. **MiniMax** — Voice Clone + Voice Design APIs, Delete Voice API (search only) — UNVERIFIED.

## 9. PII redaction

- **Deepgram** — `redact` groups `pci|pii|phi|numbers|true|aggressive_numbers` + 50+ entity types (`credit_card`, `cvv`, …). **Nova streaming supports both number and entity redaction (English only); Flux (/v2/listen) supports only `numbers`/`aggressive_numbers` and rejects everything else.** https://developers.deepgram.com/docs/redaction (accessed 2026-09-24). LiveKit plugin: `redact` on constructor and `update_options` (issue #5683 closed via PR #5692; docstring lists `pci|numbers|ssn|true`). https://github.com/livekit/agents/issues/5683 (accessed 2026-09-24).
- **AssemblyAI streaming** — `redact_pii`, `redact_pii_policies`, `redact_pii_sub` (`hash|entity_name`); "only applies to final turns," `include_partial_turns` auto-false; "Audio redaction is not available for streaming." https://www.assemblyai.com/docs/streaming/pii-redaction (accessed 2026-09-24). **Not exposed in the LiveKit AssemblyAI plugin** (no PII params in stt.py).
- **Gladia / Speechmatics** — no PII params in LiveKit plugins; vendor docs not fetched — UNVERIFIED.
- **LiveKit telemetry** — `set_tracer_provider(provider, allow_pii=False)` or `LIVEKIT_TELEMETRY_ALLOW_PII=0` strips `lk.pii.*` and `gen_ai.input/output.messages` for **external exporters only**; "doesn't change what LiveKit Cloud receives." https://docs.livekit.io/testing/observability/tracing/ (accessed 2026-09-24).
- **PCI pause-recording** — Twilio: `POST .../Calls/{CallSid}/Recordings/{Sid}.json` with `Status=paused|in-progress`, `PauseBehavior=skip|silence`. https://www.twilio.com/docs/voice/api/recording (accessed 2026-09-24). ## 11. Human takeover / supervisor listen-in / barge-in
